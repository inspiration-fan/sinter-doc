# 开始使用

[首页](../../README.zh-CN.md) · [English](../en/getting-started.md)

## 当前发行状态

暂未开放公开下载。本文介绍应用的基本使用流程；实际安装要求和功能范围以随后发布的版本说明为准。

## 准备你的 Mac

- Apple Silicon Mac。
- 应用目标为 macOS 14 或以上；特定引擎或计算路径可能有更严格的要求。
- 为模型文件预留磁盘空间，并保留足够的运行内存。应用会检查设备及模型兼容性。

当前开发验证不能代替所有设备和最低系统版本的发行验收。

## 首次使用

1. 在「我的 Mac」查看设备状态和可用内存。
2. 打开「模型工厂」，下载模型或添加已有模型文件夹。
3. 选择推理引擎并加载兼容模型。
4. 前往「本地对话」，创建对话并发送消息。
5. 需要让其他应用调用时，前往「API 服务」配置模型、端口和访问密钥。

对话历史保存在本机。界面支持简体中文和英文，可通过侧栏的语言选项切换。

## 模型文件放在哪里

添加已有模型时可以选择「使用原文件夹」或「复制到模型库」。前者保留原目录，后者额外保存一份副本；移除原目录的登记记录不会删除外部模型文件。

详见[模型指南](models.md)和[API 服务](api.md)。
