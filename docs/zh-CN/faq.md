# 常见问题

[首页](../../README.zh-CN.md) · [English](../en/faq.md)

## 从哪里下载？

目前暂无公开安装包。公开版本会出现在本仓库的 Releases，并同步更新首页和发行目录。

## Sinter 和 SinterLM 有什么关系？

Sinter 是 Mac 应用，SinterLM 是自研推理引擎。应用还提供 MLX Swift LM 作为另一种引擎选项。

## 为什么模型是灰色的？

可能是设备内存不足、格式或架构不支持、引擎资源不可用，也可能是目录权限失效。查看模型卡片中的具体原因，选择兼容的引擎、模型或上下文容量。

## 已有模型必须重新下载吗？

不需要。可以选择本地模型文件夹。使用原文件夹不会额外复制一份权重。

## 微调后的模型能使用吗？

需要导出所选引擎兼容的完整模型。只有 adapter 的目录不能直接作为完整模型加载，详见[模型指南](models.md)。

## 局域网客户端为何连接不上？

确认服务已启动、已启用局域网访问、客户端使用当前网卡地址及正确端口，并带有访问密钥。客户端使用自己的 `127.0.0.1` 无法连接另一台 Mac；防火墙或网络隔离也可能阻止连接。

## 能同时使用本地对话和 API 吗？

可以共用已加载的服务模型。当前执行请求会排队；停止 API 后，本地聊天需等待模型恢复完成。

## 是否收费？

现阶段优先完善基础版，付费订阅暂缓开放。公开版本将明确说明功能范围与价格。
