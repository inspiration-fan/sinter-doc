## Release status

No public download is available yet. This guide outlines the app workflow. Installation requirements and supported features will be specified for each published release.

## Prepare your Mac

- An Apple Silicon Mac.
- The app targets macOS 14 or later; particular engines or compute paths may require more.
- Disk space for model files and enough available memory to run them. The app checks device and model compatibility.

Current development validation does not establish support for every device or the minimum OS release.

## First conversation

1. Open **My Mac** to review your device and available memory.
2. Open **Model Factory** to download a model or add an existing model folder.
3. Select an inference engine and load a compatible model.
4. Open **Local Chat**, create a conversation, and send a message.
5. To connect another application, configure your model, port, and access key in **API Service**.

Conversation history is stored locally. The sidebar language selector switches between English and Simplified Chinese.

## Existing model files

Choose **Use original folder** to retain your existing location, or **Copy to model library** to keep another copy. Removing the registration of an external folder does not delete the original model files.

Continue with the [model guide](models.md) or [API guide](api.md).
